# Colosseum

Colosseum is a simple, self-hosted competitive programming platform for having quick programming matches between peers.

This is the frontend repository. For the backend repository, see [this other repository](https://github.com/rfboerwinkle/colosseum-backend).

## Quickstart

This project uses [HTMX](https://htmx.org/) and [TailwindCSS](https://tailwindcss.com/). To preview/develop, simply open index.html through a local web server (e.g. [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)).
